Fantasy Football Weekly Score Tracker

This project is a Java-based CLI application that uses the Sleeper API to retrieve fantasy football league data and display a weekly scoreboard.

When you run the code, you will be asked for the Sleeper ID and the week you want to view. For a week, enter any number between 1 and 17.
To test whether this works, please use my league's ID: 1223004347961442304. Or if you have your own sleeper league you can use that leagues Id.

Features:
- Pulls real fantasy football data from Sleeper API
- Displays readable scoreboard with team names
- Uses JSON and REST API integration
